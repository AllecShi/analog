# analog

模拟电子技术基础 · 图解讲义（USST）

在线阅览：**https://allecshi.github.io/analog/**

对照课件逐章讲解，每个知识点配电路图、曲线和可拖动的交互演示，例题按步骤展开。

## 目录结构

```
index.html      讲义首页 / 章节目录
ch1.html ~ ch6.html   第 1~6 章正文
assets/         样式、脚本、KaTeX 公式渲染
img/ch1~ch6/    各章配图与课件原页截图（s{n}.jpg 对应课件第 n 页）
课件/           原始课件 PPT（第 1~6 章，仅供下载，不在网页中直接加载）
```

## 更新方式

网页由 GitHub Pages 直接从 `main` 分支根目录发布，推送到 `main` 后约 1 分钟内自动更新。

新增课件时，把新的课件页截图按 `s{页码}.jpg` 放进 `img/ch{n}/`，再补充对应章节的 HTML 即可。
